## 2. Что сделано в генераторе

`build_ru_reader.py` переписан по шаблону, без изменения логики сборки контента:

- **Шапка** — фиксированная, с логотипом OpenChamber (оба SVG-варианта, dark/light, инлайн), названием, кнопкой поиска с `Ctrl K`, маркером «Русский» (неактивный, без ложного переключателя), ссылкой на GitHub и переключателем темы «Тёмная / Светлая / Авто».
- **Сайдбар** — 8 групп из `sidebar.config.json` в исходном порядке, сворачиваемые `details`, активная страница — оранжевая плашка как на сайте; независимый скролл.
- **Статья** — колонка 44 rem, типографика и стили кода/таблиц/цитат/details/kbd по токенам выше; скрытые хлебные крошки убраны (на сайте их нет); у заголовков `scroll-margin-top` под фиксированную шапку.
- **Правое оглавление** — «На этой странице» по H2/H3 текущей статьи, пункт «Обзор», активный пункт следует за прокруткой (scroll-spy).
- **Поиск** — диалог в стиле сайта: полнотекстовый по всем 62 страницам, группы по разделам, сниппеты с подсветкой, `↑`/`↓`/`Enter`/`Esc`, `Ctrl+K`/`Cmd+K`, закрытие по подложке.
- **Тема** — dark/light/auto, без перезагрузки, с сохранением в `localStorage` (в `file://` обёрнуто в try/catch), `prefers-color-scheme` как запасной вариант, инлайн-скрипт в `<head>` против вспышки белым.
- **Адаптив** — <50 em: сайдбар уезжает в панель по кнопке, поиск сжимается до иконки; 50–72 em: без правого оглавления, TOC становится раскрывающимся блоком под шапкой; ≥72 em: три колонки.
- **Прочее** — кнопки копирования кода, футер с внешними ссылками и пометкой про интернет, skip-link, `aria-current` у активных пунктов, `prefers-reduced-motion`, печатные стили (только текущая статья, чёрным по белому).

Сохранено без изменений: уникальные `doc-*`-идентификаторы, алиасы английских якорей, перенос ссылок на русские главы, обработка `#doc-page--anchor`, Back/Forward через `pushState`/`popstate`.

## 4. Ограничения и отличия от эталона

- **Скриншотное сравнение не выполнялось.** По решению пользователя браузер для сверки не использовался; вёрстка собрана по измеренным CSS-токенам и структуре живого сайта, но не проверена в реальном рендере. Пиксельное совпадение не заявляется.
- **Шрифты.** `Fixel Text/Display` — проприетарные файлы сайта, в Git не добавлялись и не встраивались. Используется `Fixel Text`, если он установлен в системе, иначе системный стек (`Inter`, `system-ui`, `Segoe UI`). Отличие в начертании заголовков возможно.
- **Иконки.** Логотип — официальный SVG с сайта (инлайн). Остальные иконки — упрощённые собственные (поиск, меню, шеврон), не копии брендовых.
- **Поиск** — собственный локальный индекс вместо Pagefind: без морфологии и ранжирования Pagefind, с простым подсчётом совпадений по всем словам запроса.
- **Нет интерактивных элементов сайта**, требующих сервера: переключение языков (показан маркер «Русский»), «Edit page», внешние ссылки требуют интернета.
- **Сайдбар** получил строку «Локальная версия · 62 страницы» — её нет на сайте, она поясняет офлайн-происхождение файла.

## 5. Как пользоваться

1. Открыть двойным щелчком `D:\github\openchamber-docs\packages\docs\OpenChamber_RU_Reader.html` — сервер и интернет не нужны.
2. Поиск: `Ctrl+K` (или кнопка в шапке), `↑`/`↓` — выбор, `Enter` — открыть, `Esc` — закрыть.
3. Оглавление справа ведёт к разделам статьи; на узком экране оно сворачивается в строку «На этой странице».
4. Тема переключается в шапке; выбор запоминается.
5. Печать/PDF — штатное `Ctrl+P`, печатается текущая статья.
6. Пересборка после обновления перевода: `python packages/docs/build_ru_reader.py` из корня репозитория (нужен `pandoc` в `PATH`).
