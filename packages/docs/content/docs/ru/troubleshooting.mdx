# Устранение неполадок

Что-то пошло не так? Найдите симптом ниже и попробуйте исправление.

## Команда OpenChamber завершается или не запускается

- убедитесь, что установлен Node.js `>=24.14`
- выполните `openchamber --version`
- при необходимости переустановите последнюю версию CLI

## Веб-UI недоступен

- проверьте логи сервера командой `openchamber logs`
- убедитесь в активном порте (по умолчанию `3000`)
- сначала откройте `http://localhost:3000` напрямую, прежде чем проверять ссылки туннелей

## Ссылка удалённого доступа или туннеля не работает

- выполните `openchamber tunnel status --all`
- перезапустите туннель из того же экземпляра и на том же порту
- создайте ссылку для подключения заново, если предыдущий токен уже использовали

Полную настройку см. в [Туннелях](/tunnels/), а если у вас есть обратный прокси — в [Обратном прокси](/reverse-proxy/).

## Расширение VS Code не подключается

- убедитесь, что сервер OpenChamber работает
- проверьте, что расширение обновлено
- перезагрузите окно VS Code и повторите подключение
