# Серверы MCP

Сервер MCP даёт вашим агентам дополнительные инструменты: поиск по базе данных, вызов API или чтение сервиса, которым вы пользуетесь. Добавляйте их в **Settings → MCP**.

## Как добавить сервер

1. Откройте **Settings → MCP**.
2. Добавьте сервер и выберите его тип:
   - **local** — OpenChamber запускает команду на вашей машине. Вы указываете команду для запуска и, если нужно, переменные окружения.
   - **remote** — OpenChamber подключается к URL, который размещает кто-то другой. Вы указываете URL и любые нужные заголовки (например, токен аутентификации).
3. Сохраните. Сервер включён по умолчанию; вы можете выключить его, не удаляя.

## Где он применяется

Выберите область при добавлении сервера:

- **personal** — доступен в каждом проекте
- **project** — доступен только в текущем проекте и сохраняется вместе с другими настройками проекта

Имена серверов используют строчные буквы, цифры, дефисы и подчёркивания.
