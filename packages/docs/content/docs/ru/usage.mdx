# Использование и квоты

Страница «Использование» показывает, сколько из плана каждого провайдера вы потратили, чтобы вы видели, насколько близко вы к лимиту. Откройте её в **Настройки → Использование**.

## Что вы видите

Для каждого подключённого провайдера OpenChamber показывает:

- сколько из текущего окна вы использовали, в виде полосы
- разбивку по моделям
- индикатор темпа, чтобы понять, успеете ли вы израсходовать лимит

Вы можете выбрать, какие провайдеры отображаются, и такая же сводка доступна из выпадающего меню в шапке приложения.

## Поддерживаемые провайдеры

Использование работает для провайдеров, которые публикуют квоту, в том числе Claude, Codex, GitHub Copilot, Google, OpenRouter, Kimi, NanoGPT, z.ai, Zhipu, MiniMax, Ollama Cloud и Wafer.

Провайдер показывает использование только после того, как вы вошли в него на странице [Провайдеры](/ru/providers/). Некоторым провайдерам нужен собственный учётный ключ, который вы вводите в настройках использования — таких трое: exe.dev, Cursor и ZenMux. Если провайдер не показывает данных, обычно это означает, что этого ключа не хватает.

## Пусть агенты читают эти данные

Включите **Инструмент использования для агентов** в **Настройки → Общие → Инструменты OpenChamber**, и агенты смогут читать те же цифры: окна каждого провайдера, сколько из каждого использовано и когда он сбрасывается. Попросите агента проверить лимит перед долгой задачей или поручите [запланированной задаче](/ru/scheduled-tasks/) сообщать, как обстоят дела с вашими планами.

Агент видит то же, что эта страница, без аккаунта, под которым выполнен вход у каждого провайдера. Каждая проверка заново обращается к вашим провайдерам — так же, как открытие этой страницы. Инструмент по умолчанию выключен и работает в десктопной и веб-версии, где используется собственный сервер OpenCode от OpenChamber.
