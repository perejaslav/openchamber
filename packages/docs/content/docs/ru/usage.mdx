# Использование и квоты

Страница Usage показывает, сколько вы израсходовали из плана каждого провайдера, чтобы вы видели, насколько близки к лимиту. Откройте её в **Settings → Usage**.

## Что вы видите

Для каждого подключённого провайдера OpenChamber показывает:

- сколько вы использовали в текущем окне — в виде полосы
- разбивку по моделям
- индикатор темпа, чтобы понять, успеете ли вы исчерпать лимит

Вы можете выбрать, какие провайдеры показывать, а та же сводка доступна из выпадающего меню в шапке приложения.

## Поддерживаемые провайдеры

Использование работает для провайдеров, которые публикуют квоту, включая Claude, Codex, GitHub Copilot, Google, OpenRouter, Kimi, NanoGPT, z.ai, Zhipu, MiniMax, Ollama Cloud и Wafer.

Провайдер показывает использование только после того, как вы войдёте в него на странице [Провайдеры](/providers/). Нескольким провайдерам нужны собственные учётные данные, которые вы вводите в настройках Usage, — таких трое: exe.dev, Cursor и ZenMux. Если провайдер не показывает данных, обычно это значит, что учётных данных нет.

## Дайте агентам это читать

Включите **Agent usage tool** в **Settings → General → OpenChamber Tools**, и агенты смогут читать те же цифры: окна каждого провайдера, сколько из каждого использовано и когда оно сбрасывается. Попросите агента проверить лимит перед долгой задачей или настройте [запланированную задачу](/scheduled-tasks/), которая будет сообщать, как обстоят дела с вашими планами.

Агент видит то же, что показывает эта страница, но без аккаунта, под которым выполнен вход у каждого провайдера. Каждая проверка заново обращается к провайдерам — так же, как открытие этой страницы. Инструмент по умолчанию выключен и работает в десктопных и веб-установках, которые используют собственный сервер OpenCode от OpenChamber.
