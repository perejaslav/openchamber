# Документация OpenChamber

OpenChamber — визуальная рабочая область вокруг OpenCode (ИИ-агента для программирования, который работает в вашем терминале). Она даёт экран, где можно наблюдать за этой работой и управлять ею, вместо того чтобы жить в командной строке.

Эти документы помогут:

- установить подходящее приложение под ваш способ работы
- открыть OpenChamber для безопасного удалённого доступа
- настроить внешний вид и устранить типичные проблемы

## Для чего нужен OpenChamber

OpenChamber нужен для тех частей ИИ-программирования, которым полезен командный пункт: разветвление сессий, ревью диффов, управление терминалами, наблюдение за ходом работы инструментов, запуск действий проекта и возможность видеть всю картину, пока агент работает.
