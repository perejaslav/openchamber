# Мобильные приложения и PWA

У OpenChamber есть нативные приложения для iPhone и Android, так что вы можете следить за сессиями, отвечать агентам и управлять работой с телефона — дома по Wi-Fi или откуда угодно через [приватный релей](/private-relay/).

## Установка приложения

- **iPhone/iPad** — присоединитесь к [бета-версии TestFlight](https://testflight.apple.com/join/5ek6GU1E)
- **Android** — скачайте APK из [ночной сборки Canary](https://github.com/openchamber/openchamber/releases/tag/canary)

## Подключение к серверу

1. На компьютере, где работает OpenChamber, откройте **Settings → Remote Instances → Connect to this server** и нажмите **Add a device**.
2. Выберите **Anywhere** (или **Home network only**, если будете пользоваться телефоном только дома) и нажмите **Create QR code**.
3. В мобильном приложении нажмите **Scan QR code** и наведите камеру на код.

Приложение подключается и запоминает сервер. QR-код одноразовый, и у каждого устройства свой отзываемый токен — о том, как сопряжение остаётся безопасным, см. [Подключение устройства](/connect-devices/).

Приложение можно сопрячь с несколькими серверами и переключаться между ними в списке экземпляров; для каждого приложение показывает, доступен ли он и подключены ли вы по локальной сети или через релей.

## PWA (установка из браузера)

Не хотите магазин приложений вовсе? Веб-приложение устанавливается прямо из браузера:

- **десктопный браузер** — используйте пункт **Install** в адресной строке
- **iPhone/iPad (Safari)** — «Поделиться» → **Add to Home Screen**
- **Android (Chrome)** — меню → **Install app** / **Add to Home Screen**

Чтобы добраться до PWA из-за пределов вашей сети, понадобится [туннель](/tunnels/) и надёжный [пароль интерфейса](/security/) — нативные приложения решают это за вас через релей.

## Мобильные настройки

В **Settings → OpenChamber** несколько параметров настраивают мобильное и установленное приложение: имя установленного приложения, ориентация экрана и поведение экранной клавиатуры.
