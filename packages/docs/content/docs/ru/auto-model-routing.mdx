# Автоматический выбор модели

Выберите **Auto** в списке моделей, и OpenChamber будет выбирать модель для каждого отправленного промпта. Исправление опечатки уйдёт дешёвой и быстрой модели, а сложный баг — самой сильной. Вы один раз решаете в настройках, какая модель отвечает за какой вид задач.

## Включение

1. Убедитесь, что настроен [провайдер классификации](/classification-providers/). Для сортировки промптов Auto нужен Jev.
2. Откройте **Settings → Routing** и отметьте **Enable Auto mode**.
3. Выберите **Fallback model** (и её уровень мышления). До этого Auto остаётся скрытым.
4. Просмотрите категории ниже и задайте важным для вас собственную модель.

Когда всё готово, страница показывает **Ready**. Выберите **Auto** в верхней части списка моделей в любой сессии.

## Категории

Каждый промпт попадает в одну категорию. Четыре встроены:

| Категория | Для чего |
| --- | --- |
| Trivial | механическая работа: переименования, опечатки, форматирование, комментарии, простые команды |
| Research | чтение и объяснение кода без изменений |
| Implement | понятное изменение: функция с известной формой, тесты, исправление с известной причиной |
| Hard | баги с неясной причиной, проектирование и планирование, безопасность, авторизация, конкурентность, миграции, деньги |

Для каждой категории можно задать:

- **Model:** пустое значение означает резервную модель
- **Thinking:** уровень мышления для этой модели
- **Agent:** агент, который выполняет такие задачи; пустое значение оставляет агента, которого использовало бы поле ввода

Jev сортирует промпты, читая названия и описания категорий, поэтому описания работают как инструкции. Говорите, что относится к категории, а что нет. Категории можно изменять, отключать, удалять и добавлять, а встроенную — восстановить, если передумаете. Для Auto должны быть включены хотя бы две категории.

## Что происходит при отправке

1. OpenChamber отправляет Jev ваше сообщение и короткий фрагмент последних нескольких ходов.
2. Jev выбирает категорию и сообщает, насколько он уверен.
3. Сессия переключается на модель, уровень мышления и агента этой категории, и ваше сообщение уходит.

Каждое сообщение сортируется заново, поэтому сессия может перейти от дешёвой модели для быстрого вопроса к самой сильной для следующего запроса. Поле ввода продолжает показывать **Auto**, а элементы управления агентом и мышлением скрыты, потому что ими распоряжается категория.

Резервная модель отвечает, когда:

- Jev недостаточно уверен (меньше 60 % уверенности)
- Jev даёт сбой или отвечает дольше четырёх секунд
- у категории нет собственной модели

Выбор любой настоящей модели в списке выводит сессию из Auto. Выберите **Auto** снова, чтобы вернуться. Также можно сделать Auto вариантом по умолчанию для новых сессий в **Settings → Sessions**.

## Где это работает

Auto работает на сервере OpenChamber: в десктопном приложении, веб-приложении и на телефоне, подключённом к любому из них. В VS Code Auto нет, потому что расширение общается с OpenCode напрямую.
