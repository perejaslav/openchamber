# Провайдеры, модели и агенты

Прежде чем OpenChamber сможет что-то сделать, ему нужен хотя бы один подключённый провайдер ИИ. Эта страница рассказывает, как подключить провайдера, выбрать модель и настроить агентов.

## Подключение провайдера

1. Откройте **Settings → Providers**.
2. Откройте меню **Add provider** и выберите провайдера, который ещё не подключён, или нажмите **Other / Custom** для эндпоинта, совместимого с OpenAI.
3. Войдите одним из двух способов, в зависимости от провайдера:
   - **API key** — вставьте ключ и сохраните.
   - **Sign-in (device flow)** — OpenChamber показывает ссылку и короткий код. Откройте ссылку, введите код и подтвердите. OpenChamber завершит подключение сам.

### Провайдеры Other / Custom

Для шлюзов, кампусных LLM, Ollama, LiteLLM и подобных API, совместимых с OpenAI:

1. Выберите **Other / Custom** в списке провайдеров.
2. Введите ID провайдера, отображаемое имя, базовый URL (`http://` или `https://`), ключ API (или `{env:VAR_NAME}`) и хотя бы один id или имя модели.
3. При желании перечислите уровни размышления модели (например, `low, medium, high`). Каждый уровень появится в средстве выбора варианта модели в чате — так же, как у встроенных провайдеров.
4. При желании добавьте заголовки запросов. Для шлюза, которому нужен mutual TLS, добавьте пути к его клиентскому сертификату и закрытому ключу в разделе **Client certificate** (OpenCode 2.3.0 или новее); зашифрованному ключу также нужна его парольная фраза, лучше в виде `{env:VAR_NAME}`.
5. Сохраните — OpenChamber запишет блок провайдера в конфигурацию OpenCode и сохранит ключ в авторизации OpenCode (буквальные ключи) либо запишет ссылку `{env:VAR}`.
6. Чтобы изменить свой существующий провайдер, откройте его и нажмите **Edit**.

Своим провайдерам нужен ключ API или `{env:VAR_NAME}`, прежде чем они будут считаться полностью подключёнными. Без учётных данных модели могут появиться, но вызовы из чата будут завершаться ошибкой.

Когда провайдер показывается как подключённый, его модели становятся доступны в чате.

Чтобы отключить, откройте провайдера и выберите удаление его входа.

## Выбор модели

Модель выбирается там, где вы работаете:

- в чате используйте средство выбора модели в строке сообщения, чтобы задать провайдера и модель для этой сессии
- для агента задайте модель по умолчанию (ниже)

## Настройка агентов

Агент — это именованная настройка: модель, характер и то, что ему разрешено делать.

1. Откройте **Settings → Agents**.
2. Выберите агента или создайте нового.
3. Отредактируйте любое из:
   - **description** — для чего нужен агент
   - **model** — его модель по умолчанию
   - **temperature** — насколько творческие его ответы
   - **prompt** — постоянные инструкции, которым он всегда следует
   - **tool rules** — какие инструменты ему можно использовать

## Где хранятся данные входа

Данные входа провайдеров хранит OpenCode, а не OpenChamber, поэтому они общие с CLI OpenCode. Если вы задаёте одного и того же провайдера в нескольких местах, побеждает более конкретная настройка: настройка для проекта переопределяет вашу личную.
