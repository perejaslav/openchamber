# Быстрый старт

## Самый быстрый путь

1. Установите [OpenCode](https://opencode.ai).
2. Установите CLI OpenChamber (однострочная команда есть в разделе [Установка](/install/)).
3. Запустите `openchamber --ui-password be-creative-here`.
4. Откройте URL, который выведет CLI (обычно `http://localhost:3000`).
5. Чтобы пользоваться OpenChamber с телефона, запустите [туннель](/tunnels/) и отсканируйте QR-код.

В браузере вы увидите список сессий OpenChamber. Если он загрузился, всё работает.

Используйте надёжный пароль к интерфейсу (UI password), особенно если собираетесь открыть экземпляр в интернет.

Если страница не загружается, загляните в раздел [Устранение неполадок](/troubleshooting/).

## Какое приложение выбрать?

- используйте **десктопное приложение** для повседневной работы на macOS, Windows или Linux
- используйте **веб-версию** для удалённого доступа и просмотра с телефона
- используйте **VS Code**, чтобы сессии были прямо рядом с кодом
