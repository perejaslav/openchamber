# Темы

OpenChamber поддерживает встроенные темы и пользовательские JSON-файлы тем.

## Импорт темы из VS Code

Откройте **Settings → Appearance → Import VS Code theme**, чтобы искать в Open VSX. В результатах показываются иконка, название и автор. Выберите пакет, сравните предпросмотры цветов и импортируйте нужные варианты. Пакетный импорт оставляет текущую тему активной. Open VSX — отдельный каталог; темы, опубликованные только в Microsoft Marketplace, могут там не появиться.

Используйте **Choose JSON file** для локального файла `.json` или `.jsonc` размером до 512 KiB. Десктоп открывает локальную папку `~/.vscode/extensions`, если она есть. OpenChamber преобразует цвета интерфейса, общей подсветки синтаксиса и diff, затем выбирает тему файла и светлый или тёмный режим. Иконка корзины рядом с импортированной темой в выпадающем списке удаляет её с подключённого сервера. Удаление выбранной темы возвращает тему по умолчанию для этого режима.

Тема сохраняется на подключённом сервере OpenChamber, в том числе при импорте с десктопа или с телефона. Повторный импорт того же файла не создаёт дубликат и не перезаписывает тему, отредактированную на сервере. Расширение для VS Code вместо этого следует собственной теме VS Code.

Если файл использует `include` или ссылается на отдельный файл токенов, выполните **Developer: Generate Color Theme From Current Settings** в палитре команд VS Code и импортируйте сгенерированный JSON.

## Добавление пользовательской темы

1. Создайте каталог тем:

```bash
mkdir -p ~/.config/openchamber/themes
```

2. Скопируйте [JSON встроенной темы](https://github.com/openchamber/openchamber/tree/main/packages/ui/src/lib/theme/themes) или [стартовый пример](https://github.com/openchamber/openchamber/blob/main/docs/CUSTOM_THEMES.md#create-your-own-theme) в этот каталог как `my-theme.json`. Задайте уникальный `metadata.id` и собственное `metadata.name`, затем отредактируйте цвета.
3. Откройте **Settings → Appearance**. OpenChamber подхватит новый файл в течение пары секунд.
4. Выберите свою тему в выпадающем списке. Она применится сразу.

Сохранённые правки появляются так же, во всех открытых окнах. **Reload themes** читает папку сразу. Для пары светлая/тёмная создайте два файла с разными ID и задайте `metadata.variant` как `light` или `dark`. Выберите каждый в соответствующем выпадающем списке.

Начните с фонов, основного текста и акцента. Держите границы и выделенные строки неброскими, а инлайн-коду дайте собственный читаемый цвет. Проверьте палитру в чате, настройках и diff. Пользовательский JSON сохраняет заданные вами цвета; автоматические подстройки, которые применяются при импорте из VS Code, к этим файлам не применяются.

## Расположение темы

- macOS/Linux: `~/.config/openchamber/themes/`

Эта папка принадлежит машине, на которой запущен ваш сервер OpenChamber. Если вы подключаетесь к удалённому серверу, сохраняйте файлы там. Пользовательский каталог данных OpenChamber использует собственную папку `themes`.
