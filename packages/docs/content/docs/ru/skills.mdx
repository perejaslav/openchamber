# Навыки

Навык (skill) — переиспользуемый набор инструкций, который агент подключает, когда это уместно: например, «как мы пишем сообщения коммитов» или «наши соглашения по API». Управлять ими можно в **Settings → Skills**.

Чтобы установить готовые навыки вместо собственных, см. [Каталог навыков](/skills-catalog/).

## Создание навыка

1. Откройте **Settings → Skills**.
2. Создайте навык, задайте ему имя и короткое описание. По описанию агент решает, когда навык применим, поэтому сделайте его конкретным.
3. Напишите инструкции. Добавьте вспомогательные файлы, если навыку они нужны.
4. Выберите, где он будет храниться:
   - **personal** — доступен в каждом проекте
   - **project** — доступен только в текущем проекте

## Использование навыка в чате

Введите `$` в любом месте сообщения, в том числе в начале, чтобы открыть выбор навыка, затем выберите один. Агент загрузит инструкции этого навыка для ответа.

`/` в самом начале сообщения открывает [команды](/chat-input/), в которых навыков нет.
