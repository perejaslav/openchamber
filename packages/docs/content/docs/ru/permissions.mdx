# Разрешения и защита

Каждое действие агента (запуск команды, правка файла, вызов инструмента MCP, загрузка страницы) сначала проходит через правила разрешений агента. Режимы разрешений OpenChamber решают, что происходит, когда правило говорит «ask».

## allow, ask и deny

Правила разрешений живут в OpenCode. Каждое правило задаёт действию один из трёх исходов:

- **allow:** агент действует дальше
- **deny:** действие блокируется
- **ask:** агент останавливается и ждёт ответа

По умолчанию большинство действий разрешено. OpenCode спрашивает только перед тем, как агент затронет папки вне проекта или прочитает файлы `.env`. Добавьте свои правила, чтобы, например, спрашивать перед любой shell-командой. Формат правил описан в [документации OpenCode о разрешениях](https://opencode.ai/v2/docs/permissions/), а посмотреть разрешения агента в OpenChamber можно в **Settings → Agents**.

Режимы разрешений меняют только то, кто отвечает на «ask». Они никогда не снимают «deny», а «allow» вообще не спрашивает.

## Три режима

| Режим | Кто отвечает на «ask» |
| --- | --- |
| **Ask every time** | Вы. Каждый запрос ждёт вашего ответа. |
| **Safety net** | Jev пропускает обычные действия, а рискованные оставляет вам. |
| **Accept everything** | OpenChamber, всегда «да». Каждый запрос разрешается сразу, без проверок. |

**Accept everything** ничего дополнительного не требует: он просто считает каждый «ask» разрешённым. Включайте его, когда доверяете задаче и не хотите, чтобы вас прерывали.

## Переключение режимов

- **Для одной сессии:** нажмите кнопку со щитом в поле ввода чата. Каждое нажатие переключает на следующий режим.
- **Для новых сессий:** выберите режим по умолчанию в **Settings → Sessions → Permissions**. Существующие сессии сохраняют свой режим.

Субагенты следуют режиму сессии, которая их запустила.

## Защита

В этом режиме OpenChamber спрашивает [Jev](/classification-providers/) о каждом запросе: это рутина или решать должны вы? Чтение, сборка, запуск тестов, правка файлов проекта и обычные коммиты проходят. Переписывание истории git, удаление данных, изменение системы, деплой, публикация куда-либо или отправка файлов наружу ждут вас, как и всё неясное.

Придержанный запрос показывает обычную карточку разрешения с одной дополнительной строкой — **The safety net held this action for you to decide** — и тем, что это за действие. Если Jev не может ответить за четыре секунды, действие тоже ждёт вас. Защита никогда не разрешает действие из-за того, что проверка не удалась.

Защите нужен [провайдер классификации](/classification-providers/). Без него кнопка со щитом её пропускает, а в Settings она отключена.

## Продолжает работать, пока вас нет

Режим живёт на сервере OpenChamber, поэтому он продолжает отвечать на запросы после того, как вы закрыли вкладку или заблокировали телефон, и переживает перезапуски.

> В VS Code защиты нет. Расширение предлагает Ask every time и Accept everything и отвечает на запросы только пока открыта панель OpenChamber.
