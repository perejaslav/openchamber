# Туннели в десктопе

Десктопное приложение может создать туннель в **Settings → OpenChamber → Tunnel**. В этом случае запускать OpenChamber из CLI не нужно.

## Установка провайдера

OpenChamber запускает CLI провайдера на вашей машине. Сначала установите провайдера, которым хотите пользоваться:

```bash
brew install cloudflared
brew install ngrok
```

Cloudflare использует `cloudflared`. Ngrok требует аккаунт ngrok и authtoken из панели ngrok:

```bash
ngrok config add-authtoken <your-ngrok-token>
```

Для Tailscale установите [приложение Tailscale](https://tailscale.com/download) и войдите.

## Запуск из приложения

1. Откройте **Settings → OpenChamber → Tunnel**.
2. Выберите **Cloudflare**, **Ngrok** или **Tailscale**.
3. Выберите тип туннеля и нажмите **Start tunnel**.
4. Отсканируйте созданный QR-код телефоном.

Ngrok сейчас поддерживает быстрые туннели. Cloudflare поддерживает быстрые туннели и управляемые режимы Cloudflare. Tailscale предлагает **Serve**, который могут открыть только устройства в вашем tailnet, и **Funnel**, который может открыть кто угодно в интернете. Если Tailscale сначала требует включить HTTPS или Funnel для вашего tailnet, рядом с ошибкой появляется кнопка **Open approval page**; подтвердите там и запустите снова.

## Защита доступа

Даже когда URL провайдера публичен, OpenChamber всё равно защищает доступ своим токеном подключения. Созданная ссылка подключения содержит одноразовый токен, имеет срок жизни (TTL), а старые неиспользованные ссылки отзываются, когда вы создаёте новую или останавливаете либо перезапускаете туннель.
