# Иконки проектов

Иконка проекта помогает с первого взгляда отличать проекты друг от друга. OpenChamber пытается найти иконку для вас, а свою вы можете задать всегда. Управляйте этим в **Settings → Projects**.

## Автоматический поиск

Когда вы добавляете проект, OpenChamber ищет в нём файл `favicon` и использует его как иконку проекта. Если в вашем репозитории уже есть favicon, иконка обычно просто появляется — делать ничего не нужно.

## Своя иконка

Откройте **Settings → Projects** и загрузите изображение (PNG, JPEG или SVG, до 5 МБ). Своё изображение имеет приоритет над найденным автоматически. Вместо этого можно выбрать цвет или удалить изображение, чтобы вернуться к автоматическому поиску.
