# Мультизапуск

Мультизапуск запускает несколько сессий из одной формы — удобно, чтобы попробовать одну задачу с разными моделями и сравнить результаты. Откройте его из выбора модели в поле ввода чата (**Run on several models**) или из палитры команд (**Run in parallel**).

## Запуск мультизапуска

1. Откройте лаунчер мультизапуска.
2. Выберите проект и назовите группу запусков.
3. Напишите промпт и выберите модели, с которыми его запускать.
4. Решите, **изолировать запуски** (isolate runs).
5. Запустите.

Каждая модель получает собственную сессию, и все они начинают с вашего промпта.

## Изолированные запуски

Включите **isolate runs**, чтобы каждый запуск получил собственное [рабочее дерево](/worktrees/) и ветку, и они никогда не трогали одни и те же файлы. Для этого нужен git-репозиторий — для папок, которые им не являются, функция отключается автоматически. Выберите ветку, от которой запуски начинаются.

Без изоляции каждый запуск — обычная сессия в папке проекта.

## Сравнение результатов

Каждый запуск — обычная сессия, которую можно открыть, прочитать и оставить или отбросить. Если вы запускали их, чтобы сравнить подходы, проверьте их рядом и продвиньте дальше лучший.

Если один запуск не удалось начать, остальные всё равно стартуют — просто сессий будет меньше, чем вы просили.
