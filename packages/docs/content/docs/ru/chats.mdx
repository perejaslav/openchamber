# Чаты

Чат — это обычный разговор с агентом вне любого проекта. Он нужен для вещей, не связанных с вашими кодовыми базами: как пропатчить KDE под FreeBSD, что делает регулярное выражение, черновик письма. Агент работает во временной папке, без репозитория, без ветки, и контекст ваших проектов не давит на разговор.

## Начать чат

Самый прямой способ — **+** в разделе **Chats** боковой панели. На телефоне нажмите **New chat** вверху списка сессий.

**Mod+N** (Cmd+N в macOS, Ctrl+N на остальных системах) и **New Session** в палитре команд открывают новую сессию там, где вы создавали её последней: чат, если последней новой сессией был чат, иначе ваш проект. Переключить её на Chats можно до отправки первого сообщения.

## Модель и агент

Новые чаты начинаются с модели, уровня размышления и агента, заданных в **Settings → Sessions → Chats**. Чаты, которые запускает агент, тоже их используют, как и чаты из запланированной задачи, настроенной на значения сессии по умолчанию. Пустое поле берёт значение из **New sessions** на той же странице. Уровень размышления принадлежит своей модели: если модель для Chats пуста, чат берёт модель из New sessions вместе с её уровнем. Если пуст только уровень для Chats, чат использует уровень, который вы последний раз выбирали для этой модели, а затем уровень из New sessions, когда оба поля называют одну и ту же модель. До отправки в чате всё равно можно выбрать другую модель или агента.

## Где живут чаты

У чатов свой раздел вверху боковой панели, выше [In work](/sessions-in-work/) и ваших проектов. Они сортируются как другие сессии, сначала самые свежие по активности, а закреплённые чаты остаются сверху. Раздел показывает три последних чата; **Show more** загружает остальные. Раздел сворачивается, как и любой другой.

На телефоне чаты находятся над списком проектов в панели сессий.

## Что чат может и чего не может

Каждый чат получает свою пустую папку, поэтому агент всё равно может создавать и редактировать там файлы: скрипт, быстрый прототип, сконвертированный документ. Чего у чата нет:

- статуса git, веток и рабочих деревьев
- перехода в работу: чаты никогда не появляются в [In work](/sessions-in-work/)
- выполнения плана в новой сессии
- старта из issue Linear

Заметки, todo и планы работают. Все чаты делят один набор, отдельный от ваших проектов.

Чат остаётся чатом. Перенести готовый чат в проект нельзя; если разговор перерос в настоящую работу, начните сессию в проекте и перенесите туда полезное.

## Архив и удаление

Архивируйте чат, чтобы скрыть его из списка. Удалите, чтобы убрать его навсегда вместе с папкой, как только ею больше не пользуется ни одна другая сессия (форк или субагент).

## Где лежат папки

Папки чатов лежат в `~/.config/openchamber/chats`, по одной папке с датой на день. Если вы перенесли данные OpenChamber через `OPENCHAMBER_DATA_DIR`, они находятся в этой папке. Чтобы держать чаты в другом месте, задайте `OPENCHAMBER_CHATS_DIR`; см. [Переменные окружения](/environment/). Это важно, когда OpenCode работает под другим пользователем и не может прочитать вашу домашнюю папку.

> В VS Code чатов нет. Расширение всегда работает в той папке, которая у вас открыта. Значения по умолчанию для Chats задаются в приложении; в расширении раздела Chats нет.
