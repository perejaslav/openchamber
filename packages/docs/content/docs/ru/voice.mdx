# Голосовой режим

Голосовой режим позволяет диктовать сообщения и слушать ответы. Включите его в **Settings → OpenChamber → Voice**.

## Чтение ответов вслух (синтез речи)

Выберите, как произносить ответы:

- **browser** использует голоса, доступные вашему браузеру. В десктопной версии на Linux установите `speech-dispatcher`, его клиентскую библиотеку `libspeechd` и голосовой движок, например `espeak-ng`. Включите службу speech-dispatcher, если ваш дистрибутив не запускает её автоматически, затем перезапустите OpenChamber.
- **OpenAI** — голоса OpenAI; вставьте ключ API и выберите голос
- **OpenAI-compatible** — любой сервис, работающий в формате OpenAI; укажите его URL и, если он нужен, ключ API. Если сервис называет эндпоинт синтеза иначе, укажите этот путь в **Endpoint path**; если оставить поле пустым, останется `/audio/speech`
- **macOS say** — встроенная команда `say`, на Mac, где она есть

После включения у сообщений появляется кнопка воспроизведения, чтобы прослушать их.

## Диктовка сообщений (распознавание речи)

Выберите, как распознавать вашу речь:

- **Local** запускает речевую модель на компьютере, где работает OpenChamber. Модель скачивается при первой диктовке, а ваше аудио остаётся на этом компьютере.
- **Server** отправляет ваше аудио в совместимый с OpenAI сервис распознавания. Укажите его URL и, если он нужен, ключ API. Если эндпоинт распознавания не `/audio/transcriptions`, задайте **Endpoint path**. Если оставить поле пустым, останется значение OpenAI по умолчанию. Чтобы помочь модели с именами, терминами или несколькими языками речи, опишите их в **Transcription prompt**, например «Spanish and English. Terms: OpenChamber». Оно отправляется с каждым запросом; используют его только модели, которые принимают промпт, а некоторые сервисы вместо этого отклоняют запрос.

Локальные модели:

- **Parakeet v3** — модель по умолчанию. Она знает 25 европейских языков, среди них английский и украинский, и работает быстрее всех. Если вы уже диктовали с Parakeet v2 до того, как v3 стала моделью по умолчанию, вы остаётесь на v2, пока не выберете другую модель.
- **Parakeet v2** знает только английский.
- **Whisper large-v3 turbo** знает 99 языков. Она примерно в девять раз медленнее Parakeet, поэтому длинная диктовка появляется через несколько секунд.
- **Qwen3-ASR 0.6B** знает 30 языков, включая китайский, японский, корейский и арабский. Украинского у неё нет.
- **Whisper tiny** — самая маленькая по объёму загрузки, для медленных компьютеров.

Модели Whisper и Qwen3-ASR определяют язык сами, и на короткой фразе могут ошибиться. Укажите код своего языка в **Language** под списком моделей, например `uk` или `en`, и они перестанут угадывать.

Включите **Fix misheard words**, чтобы ваша Small Model (Settings → Sessions → Small Model) прошлась по тексту после того, как вы остановитесь. Она заменяет слова, которые речевая модель расслышала неверно, и убирает слова-заполнители вроде «uh». Затем текст уходит провайдеру Small Model и появляется через секунду-две. Без Small Model текст вставляется так, как был услышан.

Ключи API, которые вы вводите для этих сервисов, хранит сервер OpenChamber, а не ваш браузер. Введите ключ и нажмите Enter, чтобы сохранить его; после этого поле показывает, что ключ сохранён, а крестик удаляет его.

## Заметка для телефонов

Для чтения ответов вслух на телефоне надёжнее всего варианты OpenAI или OpenAI-compatible — мобильные браузеры ограничивают встроенные голоса.
