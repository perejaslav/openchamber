# Каталог навыков

Каталог навыков позволяет устанавливать навыки, опубликованные другими людьми, вместо того чтобы писать свои. Откройте его в **Settings → Skills → Catalog**.

О том, как писать свои навыки, см. [Навыки](/skills/).

## Установка навыка

1. Откройте каталог.
2. Просмотрите встроенные источники — например, репозиторий навыков Anthropic — или воспользуйтесь поиском.
3. Выберите навык и установите его.
4. Выберите, куда устанавливать: для всего, что вы делаете, или только для текущего проекта.

Если навык с таким же названием уже существует, OpenChamber спросит, что делать: пропустить его, перезаписать или решать для каждого навыка отдельно.

## Добавление своего источника

Любой Git-репозиторий можно добавить как источник, указав его имя `owner/repo` или полный Git URL. Приватным репозиториям нужен настроенный доступ на вашей машине (SSH-ключ или сохранённые учётные данные); если источник не может пройти аутентификацию, каталог говорит об этом, а не падает молча. Чтобы использовать ветку или тег, отличные от ветки по умолчанию, добавьте их после `#`: `owner/repo#develop` или `https://github.com/owner/repo.git#v1.0.0`.
