# Подключение устройства

Сопрягите другое устройство — мобильное приложение, десктопное приложение или браузер на другой машине — со своим сервером OpenChamber, отсканировав одноразовый QR-код. Это рекомендуемый способ подключения устройств: не нужно открывать порты и вводить адреса.

## Сопряжение устройства

1. На машине, где запущен OpenChamber, откройте **Settings → Remote Instances → Connect to this server** и нажмите **Add a device**.
2. Дайте устройству имя (например, *My iPhone*), чтобы потом его узнать.
3. Выберите, где вы будете использовать устройство:
   - **This computer only** — для приложений на этой же машине
   - **Home network only** — подключается напрямую по вашему Wi-Fi. Если флажок **Also allow the encrypted relay when away from home** снят, устройство не работает вне этой сети и не получает уведомлений, потому что уведомления доходят до телефона через интернет
   - **Anywhere** — работает дома и вне дома; трафик вне дома идёт через [Приватный релей](/private-relay/), туннель со сквозным шифрованием, не требующий настройки
4. Нажмите **Create QR code**.
5. На другом устройстве отсканируйте код:
   - **мобильное приложение** — нажмите **Scan QR code** на экране подключения (или в списке экземпляров)
   - **десктопное приложение** — вместо этого скопируйте ссылку подключения и откройте её на машине с десктопным приложением, которое спросит подтверждение перед подключением. Её также можно вставить в **Settings → Remote Instances → Other OpenChamber servers → Import Link**

Диалог закроется сам, как только устройство подключится, и устройство появится в списке с актуальным статусом. Вот и всё — вы подключены.

## Почему сопряжение безопасно

- **QR-код одноразовый.** Он перестаёт работать в момент, когда устройство его использует, и истекает сам, если его так и не использовали.
- **У каждого устройства свой токен.** Сканирование кода никогда не раскрывает пароль интерфейса, и токен одного устройства нельзя использовать, чтобы выдать себя за другое.
- **Контроль остаётся у вас.** Каждое сопряжённое устройство указано с именем, платформой и статусом соединения — отозвать любое можно в любой момент.
- **Трафик вне дома шифруется сквозным образом.** В режиме **Anywhere** трафик вне вашей сети идёт через [Приватный релей](/private-relay/), который не может прочитать проходящие через него данные.

## Управление сопряжёнными устройствами

**Settings → Remote Instances → Connect to this server** перечисляет все устройства, которые могут добраться до этого сервера, с зелёной точкой, когда устройство онлайн, и указанием, подключено ли оно по локальной сети или через релей.

- **Revoke** сразу отключает устройство. Если передумаете, сопрягите его снова по новому QR-коду.
- **Clear revoked** приводит список в порядок.

Одно и то же физическое устройство сохраняет одну запись, даже если позже войдёт снова — дубликатов не будет.

## Подключение из командной строки

Если сервер работает без интерфейса (headless, интерфейс не открыт), создайте ссылку подключения в терминале на этой машине.

Для устройства в той же сети:

```bash
openchamber connect-url --port 3000 --qr
```

Для устройства, которое должно подключаться **откуда угодно**, — то же самое, что выбрать **Anywhere** в диалоге:

```bash
openchamber connect-url --relay --qr
```

Ссылка с `--relay` несёт оба маршрута, как и диалог: устройство подключается напрямую по вашей локальной сети, когда может добраться до сервера, и переходит на [Приватный релей](/private-relay/), когда оно вне дома. Релей запускается сам: работающий экземпляр подхватывает ссылку в течение минуты, остановленный — при следующем запуске.

> Прямой маршрут работает, только если сервер действительно слушает в вашей сети. По умолчанию OpenChamber слушает только саму машину — запустите его с `--lan`, чтобы он был доступен по Wi-Fi. Команда предупреждает (`[LAN_UNREACHABLE]`), когда прямой маршрут ссылки не будет работать с других устройств; ссылка с `--relay` тогда всё равно работает, только всегда через релей.

Выведенная ссылка и QR-код работают точно так же, как из диалога настроек — одноразовые, с истечением срока, отзываемые.

Чтобы сопрячь десктопное приложение, откройте выведенную ссылку на машине, где оно запущено. Приложение попросит подтверждение и затем подключится. На macOS:

```bash
open 'openchamber://connect?v=2&p=...'
```
