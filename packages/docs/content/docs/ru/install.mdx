# Установка

Выберите приложение, которое подходит под ваш способ работы:

- десктопное приложение для macOS, Windows и Linux
- веб-приложение, запускаемое через CLI, которое можно установить как приложение на телефон (PWA)
- расширение для VS Code, а также для Cursor, Windsurf и Trae
- мобильные приложения для iPhone и Android, в открытой бете

## Десктоп

Скачайте последнюю сборку со [страницы загрузки](https://openchamber.dev/download/) или из [GitHub Releases](https://github.com/openchamber/openchamber/releases/latest), затем откройте её. Сборки для Linux поставляются в виде `.deb`, `.rpm` и AppImage.

Десктопное приложение несёт собственную копию [OpenCode](https://opencode.ai) (агента для программирования на базе ИИ, на котором работает OpenChamber), поэтому больше ничего устанавливать не нужно.

## Веб + PWA

Веб-приложению нужны [OpenCode](https://opencode.ai) и Node.js 24.14 или новее на машине, где оно запускается.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

Откройте URL, который выведет CLI (обычно `http://localhost:3000`). Вы должны увидеть список сессий OpenChamber. Чтобы держать приложение под рукой, используйте пункт «Install» в адресной строке браузера и добавьте его как приложение.

## VS Code

Установите OpenChamber из [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber). Cursor, Windsurf и Trae устанавливают его из [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber). Расширению нужен установленный [OpenCode](https://opencode.ai); после этого представление OpenChamber открывается в боковой панели.

## Мобильное

Установите приложение для iPhone через TestFlight или приложение для Android из последнего релиза, затем сопрягите его с компьютером. [Мобильные приложения](/mobile/) описывают оба варианта.

## Nix

На NixOS или в любом Linux с Nix flake из репозитория OpenChamber собирает те же приложения:

```bash
nix run github:openchamber/openchamber        # web server on http://localhost:3000
nix run github:openchamber/openchamber#gui    # desktop app
```

Flake также предоставляет `packages.openchamber` и `packages.openchamber-desktop`, а также systemd-модуль `nixosModules.openchamber` с параметрами `host`, `port`, `openFirewall` и `uiPasswordFile`. Файл пароля читается через `LoadCredential` systemd, поэтому секрет с правами 0400, принадлежащий root, работает со стандартным динамическим пользователем.

Обновления проходят через flake. У упакованного OpenCode CLI встроенный автообновлятор отключён, потому что путь в хранилище Nix не может обновить себя, поэтому обновите flake и пересоберите, чтобы получить обновление.
