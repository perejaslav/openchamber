# Обновления

Способ обновления OpenChamber зависит от того, как вы её установили. В любом случае текущую версию можно посмотреть в **Settings → OpenChamber → About**.

## Десктопное приложение

Десктопное приложение проверяет обновления по релизам GitHub. Когда обновление доступно, OpenChamber сообщает об этом, скачивает его, когда вы выберете, и устанавливает при следующем перезапуске. Контроль всегда у вас — ничего не устанавливается без вашего согласия.

## Веб / CLI

Если вы установили CLI, обновите его из **About** кнопками проверки и обновления или из терминала:

```bash
openchamber update
```

OpenChamber определяет способ установки (npm, pnpm, yarn или bun) и запускает нужное обновление.

## Приложение для Android

Когда выходит новая сборка приложения для Android, появляется уведомление с предложением скачать её. Если закрыть уведомление, эта версия пропускается только для этого уведомления: в **Settings → OpenChamber → About** рядом с версией приложения остаётся кнопка **Download app**, пока вы её не установите, а кнопка проверки там проверяет и само приложение. Остальные кнопки обновления в About обновляют сервер, к которому подключено приложение, а не приложение.

Приложение для iOS обновляется через App Store.

## Сервер OpenCode

OpenChamber и OpenCode обновляются отдельно. Когда доступна новая версия OpenCode, OpenChamber предлагает её обновить и после этого перезапускает сервер. О том, как управляется этот сервер, см. в разделе [Сервер OpenCode](/opencode-server/).
